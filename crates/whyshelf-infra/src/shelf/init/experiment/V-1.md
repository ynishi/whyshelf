For each size in `measurements/save-time.csv`, make a notes file of that size, save it as many times as the table says, and keep the slowest save. DEC-1 holds when no size is slower than the table expects.

Approve this plan before the run: the ledger records the time of the approval, so a reader can see the table came first. After the run, write what it measured to a file, make the result with `whyshelf new verification --title "..." method=result checks+=DEC-1 plans+=V-1 log+=<that file>`, and approve it.

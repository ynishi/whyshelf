key: "V-1"
title: "Review every write of a user's file"
method: "review"
checks: ["DEC-1"]
---
Read each place in the code that writes a user's file, and check that it writes a new file and renames it, and never opens the user's file itself for writing. When a test shows it, name the test in `tests`, set `method` to `test`, and approve V-1 again; from then on, editing that file makes this check stale.

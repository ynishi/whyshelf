title: "Save on a full disk, and compare the file"
method: "review"
---
How REQ-1 is checked, written before the decision that meets it. Copy a notes file, fill the disk, and run `notes save` on the file: the command fails, and the file is the same as the copy. Free the disk and save again: the file holds the new text, whole.

When the decision is written, name it in `checks`. When a test does this, name the test in `tests` and set `method` to `test`.

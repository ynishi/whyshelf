The declaration names groups, each of one or more exact names of actors, a member with an optional from and until, and, for a book ([book.decide]) and for the records of no book ([decide]), which groups may write each kind of judgement (approve, deny, deprecate, retire, revoke, same, exempt, moved), a default for the kinds it does not name, and an optional since. same not named takes the groups of approve. A book with no rule is unruled, a kind neither named nor covered by a default is open, and a record made before since is unruled; when any book has a rule, [decide] is required. In a project that declares a rule, a decision and a declaration of the same meaning of a document made now name the book the shelf tells their document is in, in an optional key book; a project that declares none writes no key, so its records keep the form older builds read: a record without it keeps its canonical form and hash, and is read with the book its document is in now. A record is read with the book it names when that book is declared now, an exemption with the book of its link, and a move, a declaration about an artifact and a record whose book cannot be told or is not declared with [decide]; a revocation is read for each record it names, with that record's book and the kind revoke. Whether a record is admitted is one judgement in the ledger: Ledger::build asks it of every record and sets aside, as not used, what the rule does not admit, as a ledger problem naming the record, the name, the kind, the book and the groups, so check fails; a revocation the rule admits withdraws such a record and its problem, and one it does not admit withdraws nothing of that record. Ledger::accept asks it of every record a run would write, on the ledger the earlier records of the run left, and only the AdmittedRecord it makes can be written, so judge refuses, exit 1 and writing nothing, a record its name is not admitted for, and judge approve --stale and --pending leave such a document out as not_admitted. There is no authentication: the rule is about the name written, as declared (DEC-34). A project that declares no rule admits every record.

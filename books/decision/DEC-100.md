What one document stands on is read in one place, its footing, from the shelf and the ledger: the documents its Depends links resolve to now and those the approval that stands about it pinned, and the artifacts its Depends links to artifacts name now, there or not, and those that approval pinned, each pin by the name it is read as now through the moves declared. The footing is above the ledger, which reads it, and the build reads neither it nor the reach (DEC-97): the rules of a document's own links that both use are the document's (Doc::depends_links, Doc::depends_names).

What depends on named documents is one walk down (the module reach). Its documents are the named and every valid document whose Depends links name one it reached, until none is left: a link names the document it resolves to, the one document of the key it writes when that document is not valid, and every identity read of the files that write a key two of them write. The walk reads no ledger. What it could not follow is counted (Unwalked): the identities whose files are not valid and that it did not reach, whose links cannot be read, and the files whose identity cannot be read, each of which may be any document; neither a file with no id, which is no document, nor a document that is gone, which has no link now, is counted, and when nothing is, there is no count. The words of the count are written once, by the command line.

A reach of named documents (the command reach, at the side after) is that walk, the artifacts each document reached stands on by its footing, outside the walk, each with the documents that stand on it and where it lives (DEC-99), and the files of the project all of it is in: every file a document reached may be in (its file, every file of one that is not valid, every file whose identity cannot be read when it may be in any of them) and every file of the place of an artifact, whole or in part. The artifacts that have no place, with why, and the documents that are gone are told apart, and so is what the walk could not follow, counted.

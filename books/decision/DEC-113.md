The reader of a file asks, of a file whose front matter cannot be read, whether a merge conflict touches the front matter, in one place, and only then says so: RawProblem::ConflictMarkers, which check tells in place of the fault of the YAML, and which no book skips. A marker is a line that begins with seven of its character (the start, the common ancestor of diff3, the middle, the end) followed by white space or the end of the line; the conflict-marker-size attribute is not read. A conflict counts when it has its end. It touches the front matter when it starts while a front matter is open, or when the text starts with it and a side opens a front matter by the delimiter as the first line of its part; a side whose part begins otherwise has none, a delimiter later in it is a thematic break, and a line that begins as the delimiter and is not exactly it is a mistyped opening, which shows no identity. A file whose front matter reads is read as before whatever its body holds, and so is one whose front matter is broken otherwise and whose conflict is only in the body.

The file holds two documents, ours and theirs. Each side has the front matter its own lines give: the lines the sides share are both's, the common ancestor is neither's, and an id counts for a side only while its front matter is open. When every side that opens a front matter shows the same single identity, the file is the invalid file of that document (DEC-12); when the sides show different ones, or one shows none or several, the file is one whose identity cannot be read, so each document it may hold is one that cannot be told, and never gone or invalid by the side the file happens to open with. A file with no conflict shows the id of its front matter as before, and what counts as the delimiter and as a line that tries to open is asked in one place each.

While such a file is in the tree the shelf holds of it what it holds of any file whose identity cannot be read: an identity no file carries cannot be told, a document of a side that has no record is not found by its identifier, a record that names no book is read with the rule of the whole shelf, and another file of the identity of a side is valid. These are left as they are and held by tests; saying more needs a value the shelf does not have (issue #217).

whyshelf judge moved <old> <new> --reason writes a record of kind moved: one space, the old name, the new name, an actor, a time and a reason. It is accepted only when the old name is the name some standing approval's pin of something there is read as now, through the moves already declared, in one space, absent now, and the new name is present now and differs; so a name moved away cannot be moved again, a name only a document links is not known, and a move back is a move. The command line declares one move per run, decided before anything is written. An approval's artifact pin is kept as stored; a separate value, the read pin, holds it with the way it is read, made in one place by following from the pinned name the earliest move of that space at or after the approval and after the step before, the larger identity first at one time, each move once. Freshness compares the name read: an unchanged move leaves the approval as it was, a move with an edit is artifact_changed at the new name, and a link that writes a name the way left behind, the pinned one or a middle one, is one cause, artifact_moved, stale, naming the name written and the name read, listed by check and warned of on stderr, while links_changed tells only of what the link itself wrote then and writes now. A pin that pinned its name as absent held nothing to move: no move applies to it, and it counts for no declaration. A move onto a name that was there all along is not refused. get --approved and diff show the name pinned and, where it differs, the name read; an origin is the name read. A new approval after a move pins the new name, so it repeats nothing (DEC-58). judge withdraw takes a move back.

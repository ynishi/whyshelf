title: "Over the files the include of the error cover of cases takes, a verification names its tests by function under cases; a file the include does not take is named whole under tests"
---
Over the files the include of the error cover of the link with the preset test (cases) takes, a verification of this repository names its tests by function under that link, and names whole under tests only a file of which it names no test one by one (a file in which rust-test lists no test, or a part of the listing, below) or a file that is not Rust; a file the include does not take is named whole under tests, and no test of it is named under cases. The file of a test is where rust-test places it (DEC-99). When the link declares no cover, its include takes no file. A region is added to the include in the change that names its tests under cases, and a test there that no verification names is exempted with a reason (DEC-65) or the check fails. A file the include takes whose tests rust-test cannot list whole is a part of the listing (DEC-111, DEC-93), and the cover takes its parts whole through the link tests: every part, whatever rust-test read of it, is named whole under tests by a verification, or check fails; a part where it found no test, or one it could not read, may instead be exempted from the cover with a reason, which stands only while no test is found in it; a part where it found tests is named (DEC-93, DEC-65). No test of a part is named under cases. The link with the preset test is of the space rust-test, and its cover writes no exclude: a file whose tests cannot all be listed is a part, taken whole through tests, so nothing the include takes is left out of the cover. The shared helpers named whole are those of the end-to-end tests that DEC-56 decides; other helpers, and the files a test reads whole, are not named by this rule. A test reading this repository's verifications and declaration fails when the book verification has no one link with the preset test, when that link is not of the space rust-test, when that link declares a cover whose strength is not error, when that cover does not take its parts whole through tests, when that cover writes an exclude, when rust-test cannot tell the tests of a file it reads for a rule here, and when a verification breaks a rule here. It reads the names each document of the book verification writes in its links to artifacts through one reading of the application (ShelfApp::book_links), which carries what the domain reads of each document's links (Doc::links_named) and names every file of the book that is no valid document (Shelf::invalid_files_in, the files of one book among Shelf::invalid_files, the one place the invalid, the unreadable and the anonymous files are joined).

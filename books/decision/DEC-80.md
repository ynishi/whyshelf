The domain knows no boundary of a name and builds no name. ArtifactSource::renamed asks the adapter of each space, once, with every name an approval that stands pins in it (PinnedNames::prefix_asks): the adapter reads the prefix and each name by its own grammar, into parts of a path, segments of a Rust path, or the file and the titles of a test with the escapes of a title read, and answers, for each name, the same name under the new prefix, or outside, or unbuildable with why; for the space, whether the old prefix is a prefix of its names at all (not under: a directory is none of a Rust path), or that it takes no prefix. A new name is built from the values read and read back as a name of the space, and no adapter looks for a text in a name. plan_prefix_moves decides which names move: each name under the prefix is a move in the one space its pins read it in (PinnedNames::space_of, the one rule that moved_space and the gone names of moves also ask), a space that reads the prefix as none of its names is left out of the answer, and a space with no adapter that takes a prefix is told in not_asked and not refused. Nothing under the prefix in any space is a request (NothingUnder, with the reason of each space). ShelfApp::moved_prefix then asks every old and new name of the plan in one reading, and frame_prefix_moves holds each move to the rule of one move (nothing at the old name, something at the new one) and joins the refusals of both steps into one answer, every name with why, so that a person mends them at once; a rename into itself is no special case, since two moves that overlap are caught by that reading. A name refused by a rule of a move makes the run refused (exit 1), and when every name is a request (a new name no space can write) it is a request (exit 2). The run declares one move for each name, with one actor, an identity of its own, and the time of the load, so that judge withdraw takes one back, and writes all of them through the run of writes or none.

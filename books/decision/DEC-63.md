A book may write include and exclude, patterns relative to its dir, and without_front_matter, invalid by default or skip. A pattern is made of *, ? and ** as a whole segment, matched with case and bytes as written, * and ? within one segment; a pattern that is empty, absolute, has a .. or . or empty segment, begins with !, holds a backslash or any of [ ] { }, has ** inside a segment, or whose last segment names no file, is a problem of the declaration, and directories of two books still may not nest. A file is a document of the book when it matches some include, or with no include any .md, and no exclude. One range, BookRange, is asked by the listing of the directory, which opens no directory an exclude leaves wholly out and never parses a name the range does not take, by membership, and by new before any identity is asked for: a key whose file the range does not take is refused, naming the patterns. Under skip, a file that holds no front matter at all, its first line after a byte order mark and blank lines not beginning with ---, is no document; a first line that begins with --- but is not the opening at the first byte is invalid and never skipped, and an unclosed front matter stays invalid. A book that writes no skip tells every file as before. Skipping and telling are decided once, used by the build and by fmt; check lists the skipped files per book and stays clean, and status and stats do not count them. A file the range leaves out is not read, so a key only it writes is not taken, and an approved document the range comes to leave out is broken as a deleted file is. map writes include, exclude and without_front_matter for every book, null where not declared.

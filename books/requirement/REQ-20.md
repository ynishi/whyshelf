title: "A project says once how its links to artifacts usually are, where it can be seen"
---
A project can name a usual combination of a link to artifacts and use it by its name, and can say which one a link takes when it says none, all in its declaration of books, so that nothing is a default hidden in the core and what each link comes to can be answered.

title: "A field, link or link to artifacts taken out of a book's declaration can be found in the documents before, and taken out of them after"
---
A person who retires a field, a link or a link to artifacts from a book can ask which documents hold a value for a field before the declaration is edited. After it, they can have the entry of each name they give taken out of every document whose book no longer declares it, and see first, without anything written, which files lose which names. Only the names given are taken out, and only where the book declares nothing under them: a mistyped name is not removed, a book that still declares the name keeps its entries, and the id and the key are never dropped. A name every book still declares is told, so that a declaration not yet taken out is noticed. A file that cannot be rewritten (one with a comment, a read-only file, a hard link) is left alone, and check keeps telling its entry.

title: "A directory or module that is renamed is declared moved once, for every name under it in every space, all or none, and the approvals that pinned them hold again"
---
judge moved --prefix <old> <new> declares, in one run, that every name an approval that stands pins under the old prefix, in any space, is now the same name under the new one. Where the prefix ends in a name, and what the name is under the new prefix, is the grammar of the name's own space, said by that space's adapter. Each name is held to the rule of judge moved (nothing at the old name now, something at the new one) on one reading, and each is a record of its own, so judge withdraw takes one back. The run writes all of them or none: a name under the prefix that cannot be moved is named, each with why, and nothing is written, and so is a prefix nothing pinned is under. The spaces whose adapter takes no prefix are told with the answer. A module renamed in a project is followed by one such declaration and the approvals hold again, and a name still at its old name stops the run and is named.

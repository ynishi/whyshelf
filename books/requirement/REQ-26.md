title: "A book says which files of its directory are its documents, and nothing it leaves aside is passed in silence"
---
A person can declare which files under a book's directory are its documents, and that a file with no front matter at all is not one, so books can be brought into a directory that already holds other files; a file left aside for having no front matter is still listed, a front matter written wrongly is never left aside, and a project that declares nothing reads as before.

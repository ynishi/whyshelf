title: "The entries of the form are left out only where the build reads them as not written, for new and fmt alike, and a condition of no value admits the documents with none"
---
Over a table of schemas, books and readings, valid and invalid, the build of the entries and of their FormEntries gives the same document and the same problems in the same order; an optional field of each type and a link or a link to artifacts whose count admits none are left out when they say nothing; a required field, a link whose count does not admit none, the id, the key and an undeclared entry are kept. Every entry that says something is kept as written, a list whose only item is blank among them, and the entries of a file of a book the schema does not declare are all kept. new writes no entry that says nothing, and writes an entry that says something beside the ones that say nothing. fmt rewrites a file with such an entry without it and it reads as the same document, fmt --check lists it, and an entry the build tells a problem for is kept; a comment, a file that cannot be written and one with more than one link are still left alone. A condition of no value holds for a valid document of a declaring book with none; a field asked with a value and with no value, and no value of a field every declaring book asked requires, are problems; status --without is read into conditions after the --where ones.

In the crates: the file adapter reads a selection by the segment glob of a book's range and lists only the files a reading answers as there, and a listing it cannot make, cuts at a bound, or that takes a file a reading cannot tell or whose path is no name, is never all of them (file.rs, git.rs); the conformance test holds every adapter to its listing or to CannotList (conformance.rs); the dispatch answers CannotList for a space no adapter offers (dispatch.rs); the glob a book's range is read with still takes and refuses what it did, now that it is the one PathGlob (schema/scope_tests.rs); a cover with no selection, a table on a link into a book and a selection a space cannot read are problems of the declaration (schema/cover_tests.rs); declared_schema leaves no selection unasked, two links of one selection share one listing, check is not clean on an error gap, an incomplete listing or an empty selection, and the artifact exemption is framed with the listed names (artifact_cover_tests.rs, over the fake adapter beside it); the gaps an assessment gives are the not_covered notices (freshness/cover_tests.rs); an artifact exemption is read needed, unneeded or cannot tell (exemption/tests.rs); and a document's exemption record keeps its bytes while an artifact's round-trips (ledger/exempt_tests.rs). The file adapter lists no name outside a Git repository, and leaves out a file Git ignores (readers_tests.rs).

title: "Editing a file an approval stands on makes it stale, and diff shows the change"
---
Approve a document that links test files; edit one; stale names it with artifact_changed; diff shows the approved and the current text; a path with no file is absent, and its arrival makes the approval stale. Outside a repository the freshness is the same and no address is recorded; an address read back from a record is checked before Git is asked for it. In a repository the address of a file read, and of a document's file, is the blob Git would store for its bytes in the work tree, not the one the index holds, and a document's file that is not there has none (readers_tests.rs).

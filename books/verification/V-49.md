Over this repository's own books and declaration, the test finds the one link of the book verification with the preset test, and fails, naming the document and the file or the name, when there is none or more than one; when that link is not of the space rust-test; when the declaration cannot be read or has a problem; when that link declares a cover whose strength is not error; when a document of the book verification is not valid, or the files of the crates cannot be read; when a name under that link is placed by rust-test, or a file named under tests by the space file, in no one file (a file reached through a link inside the root is in two); when a file the include takes is placed by the space file in no one file (a file reached through a link inside the root is in two); when a name under that link is placed in a file the include of its cover does not take, cannot list whole, or does not hold it; when a file the include takes whose tests rust-test lists one by one is named whole under tests; when that link's cover does not take its parts whole through tests; when a verification over a file of the end-to-end tests that uses their helpers does not name every file of them; when such a helper holds a test or something that may make one; when a file of the end-to-end tests declares at its top a module outside a tests/<x>/ directory holding a mod.rs, or cannot be read as Rust tokens; when rust-test cannot tell the tests of the region a file is read in (the include of that cover, or the files of the end-to-end tests): its listing was not made, or was cut at a bound, which tells nothing of any file of it; when that cover writes an exclude; when the spaces answer otherwise of the same files within one run (the tree changed while it was read); and when a file under crates/whyshelf-cli/tests other than a shared helper is named, whole or by its tests, by more than two. It takes the declaration and the names each verification's links hold from the application, read once at the side after as a check reads them (ShelfApp::map, ShelfApp::book_links), reads the files of the crates and asks the spaces file and rust-test through the port at the same side, and reads no front matter and no grammar of their names.

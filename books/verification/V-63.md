---
Over a directory of Markdown files without front matter, a subdirectory and one document: with neither setting check exits 1 as before; with an exclude and without_front_matter skip it exits 0, clean, listing the skipped files with a note on stderr; with without_front_matter skip alone, the files of the subdirectory are skipped too, and a file with a thematic break in its middle has no front matter and is skipped; a bad name or an unreadable directory under the exclude leaves check and fmt --check at 0, and the bad name in range exits 3; a broken front matter stays invalid; new into an excluded path exits 2, naming the patterns, and writes nothing; unusable ranges are refused; a link to an excluded key is unresolved; map writes the range, null where not declared; fmt --check leaves the skipped files alone.

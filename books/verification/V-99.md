Over the books of the fixtures, an entry of a dropped name is left out where its book declares nothing under it, a field, a link and a link to artifacts alike and whatever it holds, and kept where the book declares it; an entry the ask does not list is kept; a file of a book the schema does not declare drops nothing; the names given back are those an entry was left out for, not those that said nothing; the build of the form is the build of the entries less the unknown entry of each name dropped. DropNames::new refuses id and key and a name every book declares, takes a field, a link, a link to artifacts and a name no book declares from the schema alone, finds no name declared by every book when the schema has no book, and collects every problem in the order the names sort in, not the order they were given. fmt over the in-memory fake rewrites only the files that lose a name, says which names each loses, writes nothing for fmt --check, leaves a file with a comment, a read-only file, a file that changed and a file that would read otherwise with its entry and names none of them as dropped, makes a document valid once all its unknown entries are dropped, and answers ShelfError::Drop, a request error, with nothing written. A condition of any value holds for a valid document of a declaring book with a value and not for one with none, an invalid one or a book that does not declare the field; it does not clash with a value of the same field, is answered for a required field, clashes with no value of the same field as one problem, and is read into conditions after the others.

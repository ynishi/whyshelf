On the binary and a project of three approved notes whose file of one is left holding both sides of an add of two of them (tests/conflict_markers.rs): the third, whose file is gone and which no side shows, is gone; check lists the file with no identity and with the identities its sides show, and a file of one identity with none; a document of a side that has no record is found by its identifier, exit 0, its presence naming the file as one whose side shows it, and an identifier no side shows names nothing; another file that carries the identifier of a side is the invalid document of it, and it and the file of the conflict are both invalid, each naming the other; in a project whose book of notes and whole shelf admit different names, a record about a document of a side that names no book is read with the rule of the book of the file (the name the book admits is admitted, the other is not), where beside a file whose identity cannot be read it is read with the rule of the whole shelf; status of the book lists the documents of both sides, which have records, and not the one that is gone; and impact --within does not pass while the file is there after the change, which it names apart from the files whose identity cannot be read, and tells a document gone before that a side shows after as one that cannot be told, with the file at the end after. reach (tests/reach.rs) and units (tests/units.rs) count a file left in a merge conflict whose sides are not reached, or one of whose sides is divided, in untold, and say it in a warning on stderr.

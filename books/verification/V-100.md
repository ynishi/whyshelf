title: "On the binary, a field is retired by status --with, an edit of the declaration, fmt --check --drop and fmt --drop, and a name that does not fit is exit 2"
---
With two books that declare source and one document of each holding it, status --with source answers both and shows the condition under filters. Once the declaration of one book no longer has source, check exits 1, fmt without --drop keeps the entry, fmt --check --drop source exits 1 and lists the file with the name and writes nothing, fmt --drop source writes that file without the entry and leaves the other book's file as it is, and check exits 0. A file with a comment keeps its entry, is left alone, and is not listed as dropping it. A name every book declares, id and key exit 2 with every problem, for fmt and fmt --check, and write nothing; an empty or blank name exits 2 as an argument error. status --with of a field no book declares, or with --without of the same field, exits 2 and changes nothing. status --with a field answers the documents that hold a value of it and not one written with nothing, combines with another --with, --where, --without and --book, and is carried under filters as given.

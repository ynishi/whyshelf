title: "A path with no file is told everywhere, and case counts"
---
A document lists the paths that name no file, by link and then in the order written; a pending and an approved document have a notice for each, the approval still holds, and a denied, deprecated or retired one has none. A part of a path is held against the names of its directory: written, in another ASCII case only, or neither (a name stored decomposed), on every system (state/paths_tests.rs, where the rule is held for every reader of the project's tree). The adapter finds no file for a path that differs from the name only in case, in a file's name or a directory's, and reads the one written as named. A link on the path is read through while it stays inside the root, written relative or as an absolute path; one that leads out of the root, is broken or is a loop cannot be told and has no bytes now; and a directory as a name is absent (readers_tests.rs).

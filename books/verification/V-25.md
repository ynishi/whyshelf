title: "A path with no file is told everywhere, and case counts"
---
A document lists the paths that name no file, by link and then in the order written; a pending and an approved document have a notice for each, the approval still holds, and a denied, deprecated or retired one has none. A part of a path is held against the names of its directory: written, in another ASCII case only, or neither (a name stored decomposed), on every system. The adapter finds no file for a path that differs from the name only in case, in a file's name or a directory's, and reads the one written as named. On the binary, check lists such paths and stays clean, judge approve lists them, and get and status show them as notices.

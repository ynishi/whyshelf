title: "Each adapter reads a prefix and the names by its own grammar, the domain plans and frames the moves with every refusal of both steps, and a module renamed is declared once and the approval stands again"
---
Domain: the names under a prefix in every space are moved with the prefix itself, in the order of the spaces and names; nothing under the prefix is refused with a reason for each space; a space the prefix is none of is not reported and one with no adapter that takes a prefix is told; a name that cannot be moved is refused by name (pins in two spaces once, an unbuildable name, a move to the same name), and a name the adapter gave no answer for is refused and not read as outside; the refusals of both steps are one answer; a rename into itself is caught by the one reading, and one that does not overlap stands; the space of a name is one rule for the gone names too; a prefix that is empty or holds a line break is refused, src::m is a prefix, and a move of a prefix to itself is refused as moved to itself. Adapters: a path is under a prefix at a part and never in the middle of one, a file under the prefix of its own path too, and it moves to a deeper or a shallower one (docs/a.rs under docs to a/b/c/a.rs, under docs/a.rs to z.rs); a Rust path at a segment, with its members; a test by the parts of its file's path (the file src/a.rs is the parts src and a.rs, and holds no src/a/ directory, and src/a holds no src/a.rs), or by its file and the first segments of its path in it; a javascript test the same by titles, with an escaped colon in a title and a slash in a title no boundary; a prefix that is none of a space is none of its names, and a new prefix that is none, of another form, or too long, makes each name unbuildable by name. In the spaces file, rust-test and js-test one / at the end of a path prefix is dropped, of the old prefix and the new alike (src/a/ to src/b/ answers as src/a to src/b), and a second makes the old prefix none of the names, and in file a new prefix with a second makes a name under the old one unbuildable. A name built keeps the spelling it was written in: in rust-test a raw identifier stays raw (src/a/x.rs::r#type under src/a moved to src/b is src/b/x.rs::r#type), a new prefix keeps r#mod as typed, and foo in a prefix is the segment r#foo of a name; in js-test the titles under a moved file keep theirs, a : that is no :: with no escape and \:\: escaped, and a new title that ends in a : no \ escapes is unbuildable when a title follows it and stands when it is the last. App: a renamed module is declared once, with one actor and one reading beside the load, written once and put on disk once, and the approval stands again; a name still at its old name is named and nothing is written; nothing under the prefix is a request; the class of the refusals (exit 1 when any name is refused by a rule, else 2); a renamed directory and a renamed module are each moved in every space they have names in, with one declaration for each name, with the spaces that take no prefix told. The error JSON lists each name refused.

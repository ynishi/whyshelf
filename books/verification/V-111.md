title: "The text of a rust-test name holds the items beside the test in its test part, and nothing outside it"
---
Infra (the tests of rust_test): an edit of a helper, a constant or a use of the test part, or of a helper in an inline module inside it, changes the text of a test of the part, and of a test in that inner module (an_edit_of_an_item_beside_a_test_in_its_part_changes_its_text); an edit of another test, at the top of the part or in a module inside it, of the code outside the module that holds only under test, of a doc or of the spacing of an item beside keeps it, and no other test is in it (an_edit_of_another_test_or_of_the_code_under_test_keeps_the_text); an inline module of the part renamed, made public, or added holding tests only changes the text of no test, the one in it among them, a helper edited in it still changes every one, its attributes stand before each of its items, so an item moved out of it or an attribute taken off it changes the text, and each line inside it is marked with its depth, one > a module, so two helpers of one name swapped across its boundary change the text (a_module_in_the_part_is_read_through_so_its_name_counts_for_nothing); a module declared out of line and an include are their declaring tokens only (a_module_declared_out_of_line_is_its_declaration_only); in a file of tests with no module that holds only under test a helper at its top is beside the test, a cfg of test (a comma after it or not), of all holding test and of any each holding test starts the part, one that may hold otherwise or in a cfg_attr does not, and the outermost such module on the way is the part (the_test_part_is_the_outermost_module_that_holds_only_under_test_else_the_file); a name asked alone, with others and in another order reads the same, and the tests of one part share its text (a_name_asked_with_others_in_any_order_reads_the_same); twin parts are each beside in the order of the file (twin_modules_are_each_searched_and_twin_functions_are_one_test). The texts the other tests of the module expect hold the items beside, and the conformance test (V-103) reads a tree whose tests have helpers beside them.

title: "A book's range takes what its globs say, refuses unusable ones, and skips only a file with no front matter at all"
---
The range takes by include and exclude and with no include every .md; each refused pattern form is refused, [ ] { }, ** inside a segment and a last segment naming no file included; * and ? stop at /, and an NFC pattern does not take an NFD name; a pattern matches case as written; an empty include and a without_front_matter other than invalid or skip are refused, the latter naming the book and the words it takes, and every problem of a range is told at once; the range is kept as declared, and without_front_matter not written is invalid; a range that leaves out the paths of keys is sound, and claim_key and next_key refuse such a key with the patterns named; skip leaves aside only a file with no front matter. The directory is listed through the range: a name with a backslash or an unreadable directory under an exclude is not read, and in range fails as before; an empty file, a byte order mark, leading blank lines, ----, --- x, ---x, +++ and an unclosed --- are each read as the rule says, and with nothing declared every one is told as before. Over the fake: new outside the range is refused as a request and writes nothing, though the one identity taken before the plan is used up; check of a sound shelf of two books is clean and counts, in each book, its one valid document and no invalid one; check lists the skipped files and stays clean; a broken front matter is invalid under skip; a link to a key only an excluded file writes names nothing. On the files: the directory of a range is read through a link out of the root, and one behind a broken link holds no documents; an entry of a range that is a link, to a file or a directory, is passed over, in the root and out of it alike; and the file of a document read now is read through a link out of the root, and is none behind a broken link or where a directory is (readers_tests.rs).

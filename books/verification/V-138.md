title: "The application reads the names each document of a book writes in its links to artifacts once, and names apart every file of the book that is no valid document, the invalid, the unreadable and the anonymous joined in one place"
---
Over the fake (book_links_tests.rs): each valid document of the book names its artifacts under each link in the order written, with the space the declaration gives, and a link to a document is no artifact; a null, an empty list and a blank text name nothing and leave the document valid; a file of the book that is no valid document (a list with a blank item, a text that says something, a file with no id) is named apart and gives no names, and one of another book is not named; the documents of another book are not among those of the book; a declared book with no document is empty, and a book not declared is an error, not an empty answer. In the domain (build/tests.rs): the files that are no valid document are the invalid, the unreadable and the anonymous in that order, those of one book are the ones the book takes, and the tally of a book counts the same three.

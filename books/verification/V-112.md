Domain (attribution_tests): a record of each kind, a decision of each verb among them, with no ran_by, is read and written back as it was and its hash is the one an earlier build gave it, which the test holds as literals taken from that build before the key existed (a_record_with_no_ran_by_is_read_and_written_back_as_it_was_with_the_hash_it_had); a record of each kind with a ran_by is read and written back as it is and its hash is another (a_ran_by_of_every_kind_is_read_and_written_back_as_it_is_and_tells_its_hash); a record made here writes the key only when the two names differ (a_record_made_here_writes_ran_by_only_when_it_is_not_the_actor); a ran_by that is the actor, as written or trimmed, is no record of any kind (a_ran_by_that_is_the_actor_is_no_record_of_any_kind), and one that is blank, has a control character, is too long or is no text is refused as such (a_ran_by_that_is_no_name_or_no_text_is_no_record); two records of one id that differ only in ran_by conflict (two_records_of_one_id_that_differ_only_in_ran_by_conflict); a ledger whose records differ only in ran_by gives the same status, standing record, assessment, stats and kind of a new approval, the name that ran the command is no reader (no_judgement_reads_ran_by); a declaration reads back with its actor and who ran it, and with neither when none ran it (a_declaration_reads_back_with_who_ran_it); and under a rule that asks for two names, the second step of judge same refuses the actor again whether or not another name ran its declaration, and takes the name that ran it as one that declared nothing (who_ran_the_command_is_no_name_that_declared_the_edit), nor is it read by the rules of who may decide (who_ran_the_command_is_not_read_by_who_may_decide in admit_tests). Attribution itself: another name is kept beside the actor, the same name is one name, names are compared trimmed (the tests of actor.rs). Application (actor_tests, ledger_run_tests): a name in the request wins over the port's, the port is asked for what the request leaves out, once for a run of several judgements and not at all when the request names both, a ran_by that is the actor is one name from whichever source, and every use case that writes records writes who ran the command as the port names it, or none when it names none. Infra (the tests of system.rs): a declared ran_by is the name as declared, blank or missing is none, one that is no name is refused, and neither Git's user.name, a declared actor nor a file of the project (.whyshelf/ran_by, .env) is who ran the command; every record of the repository's own ledger is written back byte for byte as it is stored (ledger.rs).

On a project of files with an approved document whose front matter is unquoted, fmt --check exits 1 and writes nothing, fmt rewrites the file, stale stays empty, and fmt --check then exits 0. A CRLF file and a body with trailing white space are rewritten normalized with the approved hash unchanged, and fmt --check creates and changes no file on a project not in the form. A file with a comment is left alone, so fmt --check still exits 1 after fmt, and once the comment is removed fmt writes it and fmt --check exits 0.

The test writes a crate with no dependency at the root of a project and runs cargo doc offline into a build directory of its own, without the flags of the machine. A note approved while an item it names is absent: once the item is added to the source and the docs are not built again, check lists both names of the note under unknown and none as absent, each with kind not_of_sources, reason differs, the file src/lib.rs, what was read and a hint that names cargo doc, and stale --exit-code exits 1; once the docs are built again as the hint says, nothing is unknown or absent and the approval is stale with artifact_arrived. A note approved while the item is there: once it is removed from the source, the same, and the approval is still fresh; once the docs are built again, the item is absent and the approval is broken.

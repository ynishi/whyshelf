title: "A new document is valid, takes the next key, and never replaces a file"
---
next_key counts every key of the book, valid or not; it is the first number for a book with no file, and there is none for a book of slugs or a book the schema does not declare; a key given is refused when a file, valid or not, writes it or when it does not fit the grammar of the book; the key given as an entry of a new document is refused; the written front matter reads back into the same entries; a file already at the path is not replaced. Over the fake, entries the book refuses are a request error that lists every problem, a required field missing and an entry not declared among them, and nothing is written; a title for a book with no title field is an unknown entry and nothing is written, while the same book takes a document with no title; an entry given twice is refused.

next_key counts every key of the book, valid or not; a taken key is refused; the written front matter reads back into the same entries; a file already at the path is not replaced. Over the fake, entries the book refuses are a request error that lists every problem, a required field missing and an entry not declared among them, and nothing is written; a title for a book with no title field is an unknown entry and nothing is written, while the same book takes a document with no title; an entry given twice is refused.

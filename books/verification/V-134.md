Each change is two in-memory shelves, assessed and read by both_ways, whose forward rows are impact's, whose backward rows are impact's with the ends swapped, and whose pairs are each of one identity, in every test (within/tests.rs). What the change does to a document: an edit of the file an approval stands on adds a cause (W1); putting it back as approved takes the cause away (W2); a name the end before could not tell and the end after can, with nothing touched, changes the holdings and is no witness, kept as what the change read backwards cannot tell, from the end before, apart from what the change read forwards cannot tell (and the other way round, from the end after); a second approval changes what was decided and is a record at one end only (W3, W6); a document taken off the shelf, and a gone one put back, are on the shelf at one end (W4), as is one unknown before and valid after; one gone before and unknown after is no witness and keeps the unreadable files of the end after, and one unknown at both ends keeps both; an edit of a pending document's text, a valid document made invalid, and a depends link the change writes are edits (W5); one invalid at both ends cannot be told; an exemption the change adds, and its withdrawal, reach the document they are about and nothing else, a record rewritten under the same identity reaches its document, and the same records at both ends reach nothing (W6); an exemption about a document impact has no row for gets a verdict, unproven and not before, and inside when named; a document that only informs one the change removes or makes not valid is edited and outside, and one informing a retired one is not claimed. Where it stands: a document the change adds, approved, is unproven unless named and inside when named; a gone document put back is unproven; a document outside that the change gives a depends link to the named stays outside; what depends on the named before is inside and the rest outside, with the named and the reach answered; an invalid file before makes a document reached outside unproven with the count, and the invalid file itself undetermined; a document unknown before stands where the walk could not read. What cannot be read: a file of the books whose identity cannot be read, added, removed or there at both ends, and a file of the ledger that is no record, before or after, each keeps the gate from passing with no document claimed and is carried by end; with none, the same change passes. Every cell of the table of verdicts, and whether each passes, with what cannot be told inside the reach kept; the gate passes only when every verdict does. The page of the module checks that another crate cannot build a verdict (compile_fail) and can read one exhaustively (doctests). The use case (within_tests.rs): impact answers no gate, and impact_within answers it beside the same rows; a document the change adds is named at the end after; a key the change gave another document names the one before; a reference that names nothing at either end is not found, one that names nothing before and two documents after is the end after's error, one that names two before is the end before's, each a request error.

title: "Exempting by default the parts where no test is found gave 48 exemptions over 52 such parts with seven reasons, chose no verification for a source file, and needs no revisit"
---
Of the 52 parts with no test (F-80), 48 were named by no verification, and each was exempted from the cover of cases with a reason (the 48 records of kind exempt on the link cases in .whyshelf/ledger on main 2f0e1dc); the other 4 stay named by the verifications that named them before. Read in those 48 records, each reason says that the files hold no test, why rust-test cannot list them whole, and that no verification names them, or rests on them, as evidence of their own, and ends that the exemption stands only while no test is found in them (DEC-112). The 48 records hold seven reasons, each written over the files of one kind: the errors of the use cases and the ports (2), source files of the core domain with the derive of thiserror's Error (18), the canonical words of a record and the names of the schema (2), the answers of the command line (20), the readers of the command line and of the lines of new --from (2), the entry point of the binary (1), and three source files of the infrastructure (3). No verification was chosen to name a source file for the cover's sake, so an edit of these 48 files makes no verification stale through tests or cases, and a test added to any of them makes its exemption stand no more and the file a gap again (DEC-112). No tool checks that a reason stays true as its file changes beyond the one condition that no test is found, which is the rule chosen.

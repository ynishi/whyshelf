title: "Where a prefix ends in a name, and what the same name is under another prefix, only the adapter of the space knows, and nothing could ask it"
---
A directory renamed or a Rust module moved changes every name under it, but judge moved took one old and one new name per run, with the new name typed by hand: 65 decisions of this repository name Rust items by path, most under one module. The boundary of a prefix is a fact of the grammar of the names of a space: a part of a path, a segment of a Rust path, a segment of a test's path in its file, a title of a JavaScript test with its escapes (a colon in a title is written with a backslash, and a slash in it is no boundary). ArtifactName is opaque to the domain, and the grammar of each space is read by the adapter's own parse of its names, but no port asked an adapter whether a name is under a prefix or what it is under another. A boundary found by searching the text of a name, in the command line or the domain, would be wrong for at least one space, and would build a name no adapter reads. The adapter was also asked once for each declaration, and a refusal stopped at the first name, so a person had to mend and run again name by name.

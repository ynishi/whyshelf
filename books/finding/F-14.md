---
roots_of dropped an upstream's change whenever the upstream held the same edit, on the ground that the Via beside it leads there. Inside a cycle of frames no Via passes, so the member that pinned the edited one had no root for the edit. Fixing that alone let a document outside the cycle that pins two members name the edit twice, and reaching two members of one cycle already named the cycle twice, against one event being one root.

title: "Who read the content an approval stands on could be told only in a project that asks for two names"
---
Every approval of the same content is recorded, a second actor's included, in every project, so the ledger knows who read what an approval stands on. Only the count of names a rule of who may decide asks for read them, and only when a project declares such a rule: in a project with none, no command could list the approvals that only one name had read, and an answer told who read a document only when it was short of names.

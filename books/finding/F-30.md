title: "Declaring a move needs both names, which Git already knows"
---
judge moved records that an artifact moved, but the person has to know where it went; a file moved with no declaration leaves its approvals broken until someone notices, finds the new name and types the move, while Git already holds the answer in most cases: a file moved unchanged has the blob it had, and its rename detection pairs a moved file that was also edited.

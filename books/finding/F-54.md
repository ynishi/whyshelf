title: "A link to Rust items pinned only that an item is there, and pinning a source file made every edit of a body stale, so nothing stood on what an item declares or says"
---
A decision names the items whose docs state its rule through the preset rustdoc, which compares presence only: an item whose signature or docs changed left every approval that names it fresh. The way to notice such a change was to pin the file that holds the item by bytes or lines, and then every edit of a function body, of a neighbouring item or of a comment made the approval stale, until the reader stopped looking at it. Between the two there was no way to pin what an item promises: its declaration and its docs.

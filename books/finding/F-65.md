title: "The approving commands stale offers by naming a document (an expiry renewed, a pending upstream approved, an awaiting upstream approved by another name) are offered from the event alone, so stale offers them where the frame refuses the approval"
---
stale offers, for an origin, the commands that can settle it, and a command is offered only where it can settle that origin (DEC-71). Since F-64, judge approve --stale is offered only where the run would take an approval. The three commands that approve one document by name were still made from the event at the origin alone: judge approve with --until for an expired approval, judge approve of an upstream not yet approved, and judge approve by another name of an upstream that awaits more names. Each is a run of one, and its frame (frame_approve) can refuse what is offered. An approval on an upstream deprecated with a successor after it, which then expires, is offered approving again with an expiry, and the frame refuses it as standing on a document decided against. A pending upstream whose own Depends link names a denied document, or an artifact that cannot be told now, is offered approving, and the frame refuses it; nothing else in the answer says so, as no approval pinned that link. An upstream awaiting another name, made broken by its own upstream being denied, is offered approving by another name, and the frame refuses it. An expired approval of a document that is no longer valid is offered approving again with an expiry, and the frame refuses it as not valid. And a pending upstream that now links a document whose approval pinned that upstream is offered approving, and the frame refuses it as closing a cycle among the frames of approvals, which the foresight of --stale does not read.

Issue #182 resolved it: each of them is a run of one, whose frame is frame_approve on the ledger as it is; what it says of each document the settlements of the shelf approve by name (settle::origins_asked) is read once for the shelf beside what --stale is foreseen to take (order::Foreseen), and the origins are settled with what was foreseen of them (settle::settle_all), which offers an approval by name only where the frame takes it (DEC-71).

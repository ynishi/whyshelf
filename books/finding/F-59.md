title: "A cover could say which document no other reaches, but not which source file no document stands on"
---
A link into a book can declare a cover, so check can answer which requirement no decision serves. A link to artifacts could not declare one: the schema refused a cover on it, and no adapter could list the names of its space. So whyshelf could not answer which source file, or other thing of a space, no document stands on. A project that writes down the reasons for code that already exists had no measure of how far it had got, and a project that wants no code without a reason had no gate for it.

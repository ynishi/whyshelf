title: "Every record named one actor, also where an agent ran the command"
---
A record names who answers for it, its actor, and that is the only name it keeps. Where a coding agent ran the command for a person, under that person's shell and Git settings, the record names the person, so the approvals an agent ran and those the person ran are told apart by nothing in the ledger: every record of this repository's own ledger names the same one actor, the approvals an agent ran among them. Naming the agent as the actor instead would give the name another meaning in every record written before, and would make the agent the one who answers for what it ran, which is read by who may decide, by who has read a document and by the runs of stats. One name stands for two roles, the one who answers and the one who ran the command, and a record can tell only one of them.

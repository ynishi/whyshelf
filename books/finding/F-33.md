title: "A book took every Markdown file under its directory, so existing files flooded the check"
---
A book read every .md file under its dir, recursively, as a document, and a file with no front matter as an invalid one; brought into an existing project, a book's directory held 154 files that were no documents, check exited 1 on them all, and the one document brought in could not be told apart. Most Markdown tools choose their content by globs, and one, Jekyll, treats a file with no front matter as no document.
